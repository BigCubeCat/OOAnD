# NashCash

## Тестовая сборка

1. Запустите

```bash
docker-compose up --build -d
```

2. Откройте тунель

ngrok ушел из РФ, используется localtunnel

```bash
npm install -g localtunnel
lt --port 8000
```

3. Настройте тунель
   3.1. перейдите по полученной после выполнения предыдущей команды ссылки
   3.2. откройте https://loca.lt/mytunnelpassword и скопируйте содержимое. Это пароль из предыдушего пункта

4. Уставновите доменное имя в боте
   нужно выставить в настройках телеграм бота домен, полученный выше
